# Опис роботи системи детекції диму та вогню

## Загальна ідея

Система призначена для надійної детекції **вогню та диму у відеопотоці** з мінімізацією хибних спрацювань.  
Для цього класичну детекцію нейромережею доповнено **трекингом об’єктів** та **вейвлет-аналізом сигналів** (temporal + spatial).

---

## Основні етапи роботи

### 1. Детекція нейромережею
Кожен кадр обробляється моделлю детекції (YOLO):
- визначаються bounding box’и
- класи: `fire`, `smoke`
- confidence score

Результат конвертується у стандартну структуру `Detections`.

---

### 2. Ремапінг класів
Класи детекції нормалізуються до внутрішніх ID системи  
(наприклад: `fire → 4`, `smoke → 5`) для уніфікованої обробки подій.

---

### 3. Трекінг об’єктів (ByteTrack)

Для кожного детектованого об’єкта запускається **ByteTrack**:
- об’єкти отримують стабільний `tracker_id`
- зберігається історія існування об’єкта між кадрами
- відсіюються короткоживучі або втрачені треки

Це дозволяє аналізувати **поведінку об’єкта в часі**, а не одиничні детекції.

---

## Нетипові та ключові механізми

### 4. Temporal wavelet analysis (часовий аналіз)

Для кожного треку ведеться історія **середнього значення червоного каналу (R)** всередині bounding box.

Далі:
- до сигналу застосовується **дискретне вейвлет-перетворення (DWT, db2)**
- аналізується найвища частотна компонента
- рахується кількість **zero-crossing**

Ідея:
- полум’я має характерне **мерехтіння (~10 Гц)**
- велика кількість zero-crossing → ознака вогню

---

### 5. Spatial wavelet analysis (просторовий аналіз)

Для кожного bbox-кропу:
- береться R-канал
- виконується 2D DWT
- обчислюється енергія високочастотних коефіцієнтів (cH, cV, cD)

Ідея:
- вогонь та дим мають **хаотичну, турбулентну текстуру**
- висока енергія високих частот → підтвердження події

---

### 6. Підтвердження події (wavelet-confirmed)

Об’єкт вважається підтвердженим, якщо:
- temporal **АБО** spatial wavelet аналіз повернув `True`

Це значно знижує:
- хибні спрацювання від світла, фар, рухомих об’єктів
- одиничні помилки нейромережі

---

## Формування подій

Після досягнення мінімальної кількості кадрів:
- трек додається у чергу подій
- формується структурований event:
  - тип (`fire` / `smoke`)
  - bounding box
  - confidence
  - ознака `wavelet_confirmed`
  - траєкторія

---

## Переваги підходу

- Комбінація **AI + signal processing**
- Аналіз не лише зображення, а й **динаміки та текстури**
- Стійкість до шуму та складних сцен
- Придатність для edge-систем та real-time роботи
